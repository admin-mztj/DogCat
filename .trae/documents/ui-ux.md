
# 微信公众号桌宠 UI/UX 设计文档

## 1. 设计系统总览

### 1.1 设计模式
| 属性 | 值 |
|------|-----|
| **模式名称** | 沉浸式互动体验 (Immersive/Interactive Experience) |
| **转化焦点** | 40% 更高参与度，需要提供跳过选项，移动端降级方案 |
| **CTA位置** | 互动完成后 + 为急切用户提供跳过选项 |
| **色彩策略** | 沉浸式体验色彩，深色背景聚焦，高亮互动元素 |

### 1.2 设计风格
| 属性 | 值 |
|------|-----|
| **风格名称** | 活力方块风格 (Vibrant & Block-based) |
| **关键词** | 大胆、活力、趣味、方块布局、几何形状、高对比度、双色调、现代 |
| **适用场景** | 初创公司、创意机构、游戏、社交媒体、年轻群体、娱乐、消费类 |
| **性能** | ⚡ 良好 |
| **无障碍** | ◐ 需确保 WCAG 合规 |

## 3. 字体系统

### 3.1 字体配对

| 角色 | 字体名称 | 权重 | 用途 |
|------|----------|------|------|
| **Heading** | Fredoka | 400-700 | 标题、宠物名称、数值显示 |
| **Body** | Nunito | 300-700 | 正文、按钮文字、状态描述 |

### 3.2 Google Fonts 引入

```css
@import url('https://fonts.googleapis.com/css2?family=Fredoka:wght@400;500;600;700&family=Nunito:wght@300;400;500;600;700&display=swap');
```

### 3.3 Tailwind 配置

```javascript
fontFamily: {
  heading: ['Fredoka', 'sans-serif'],
  body: ['Nunito', 'sans-serif']
}
```

### 3.4 字体风格特点
- **圆润友好**: 适合宠物、游戏类应用
- **温暖亲切**: 提升用户情感连接
- **易读性强**: Nunito 在小字号下依然清晰

## 6. 动画系统

### 6.1 动画时长规范

| 类型 | 时长 | 使用场景 |
|------|------|----------|
| **Micro** | 100-150ms | 按钮点击、图标切换 |
| **Short** | 200-300ms | 悬停、状态变化 |
| **Medium** | 400-500ms | 进度条更新、弹窗出现 |
| **Long** | 600-800ms | 页面切换、复杂动画 |

### 6.2 缓动函数

| 名称 | 函数 | 使用场景 |
|------|------|----------|
| **Default** | ease-out | 大多数动画 |
| **Bounce** | cubic-bezier(0.68, -0.55, 0.265, 1.55) | 弹跳效果 |
| **Smooth** | ease-in-out | 渐变过渡 |

### 6.3 宠物动画定义

| 动画名称 | 触发条件 | 效果描述 | CSS实现 |
|----------|----------|----------|---------|
| **漂浮** | 空闲状态 | 上下轻微浮动 | `translateY(0) → translateY(-10px)` |
| **眨眼** | 随机触发 | 快速眨眼 | `scaleY(1) → scaleY(0.1)` |
| **跳动** | 点击/开心 | 跳跃效果 | `translateY + scale` 组合 |
| **饥饿** | 饥饿值<30 | 肚子收缩 | `scale(0.95)` + 抖动 |
| **喂食** | 喂食动作 | 张嘴动画 | `scaleY(1.2)` + 食物飞入 |
| **摇尾巴** | 玩耍/小狗 | 尾巴摇摆 | `rotate(-15deg) → rotate(15deg)` |

### 6.4 动画性能优化

```css
/* 使用 transform 和 opacity 触发 GPU 加速 */
.pet {
  will-change: transform, opacity;
  transform: translateZ(0);
}

/* 减少动画偏好支持 */
@media (prefers-reduced-motion: reduce) {
  .pet {
    animation: none;
    transition: none;
  }
}
```

## 7. 触摸交互规范

### 7.1 触摸目标间距

| 规则 | 要求 |
|------|------|
| 相邻按钮间距 | ≥ 8px (`gap-2`) |
| 按钮最小尺寸 | ≥ 44×44px |
| 可点击区域 | 扩大到触摸目标大小 |

### 7.2 触摸事件处理

| 事件 | 处理方式 |
|------|----------|
| **touchstart** | 开始拖拽，记录初始位置 |
| **touchmove** | 更新位置，使用 requestAnimationFrame |
| **touchend** | 结束拖拽，触发弹性动画 |
| **click/tap** | 触发互动动画 |

### 7.3 触摸优化代码

```css
/* 禁用默认触摸行为 */
touch-action: none;

/* 消除 300ms 点击延迟 */
touch-action: manipulation;

/* 禁用长按菜单 */
-webkit-touch-callout: none;

/* 禁用文本选择 */
user-select: none;
```

## 10. 防错与边界处理

### 10.1 数值边界

| 数据 | 最小值 | 最大值 | 处理方式 |
|------|--------|--------|----------|
| 饥饿值 | 0 | 100 | `Math.min(100, Math.max(0, value))` |
| 心情值 | 0 | 100 | 同上 |
| 金币 | 0 | ∞ | 购买时检查是否足够 |

### 10.2 拖拽边界

| 边界 | 处理方式 |
|------|----------|
| 左边界 | `Math.max(0, x)` |
| 右边界 | `Math.min(screenWidth - petWidth, x)` |
| 上边界 | `Math.max(statusBarHeight, y)` |
| 下边界 | `Math.min(screenHeight - actionBarHeight - petHeight, y)` |

## 12. 设计交付检查清单

### 12.1 视觉质量

- [ ] 不使用 Emoji 作为图标（使用 SVG 图标）
- [ ] 所有图标来自统一图标集（Lucide/Heroicons）
- [ ] 悬停状态不会导致布局偏移
- [ ] 使用主题色而非 CSS 变量包装

### 12.2 交互

- [ ] 所有可点击元素有 `cursor-pointer`
- [ ] 悬停状态提供清晰视觉反馈
- [ ] 过渡动画平滑（150-300ms）
- [ ] 焦点状态对键盘导航可见

### 12.3 移动端

- [ ] 触摸目标 ≥ 44×44px
- [ ] 相邻按钮间距 ≥ 8px
- [ ] 禁用 300ms 点击延迟
- [ ] 支持触摸拖拽

### 12.4 无障碍

- [ ] 所有图片有 alt 文字
- [ ] 表单输入有标签
- [ ] 颜色不是唯一指示器
- [ ] 支持 `prefers-reduced-motion`

### 12.5 响应式

- [ ] 375px 小屏手机测试
- [ ] 768px 平板测试
- [ ] 1024px 小屏桌面测试
- [ ] 1440px 大屏桌面测试
- [ ] 移动端无横向滚动
